# Excel 通用脱敏工具

这个工具分两步运行：先扫描并生成可修改的脱敏方案，人工确认后再执行。扫描阶段不会修改原文件，执行阶段也只生成新文件。

Python 程序本身不写入任何客户或项目的针对性识别条件。字段识别词、内容格式和默认处理方式全部放在独立的 `default_rules.json` 中，由通用扫描引擎读取。

## 环境

- Python 3.10 或更高版本
- `openpyxl` 3.1 或更高版本

安装依赖：

```bash
python3 -m pip install -r requirements.txt
```

## 第一步：扫描并生成脱敏方案

输入可以是一个 `.xlsx`、`.xlsm` 文件，也可以是包含多个 Excel 的目录：

```bash
python3 excel_anonymizer.py scan \
  --input "/路径/原始数据" \
  --output "/路径/脱敏方案_待确认.xlsx"
```

如需使用单位自己的识别规则，复制并修改 JSON 后通过参数指定：

```bash
python3 excel_anonymizer.py scan \
  --input "/路径/原始数据" \
  --output "/路径/脱敏方案_待确认.xlsx" \
  --rules "/路径/本单位脱敏规则.json"
```

方案文件包含：

- `使用说明`：操作顺序和可使用的样式写法。
- `扫描摘要`：每个文件和工作表的扫描范围、表头位置及候选字段数量。
- `脱敏方案`：真实样例、识别类型、处理方式及脱敏后样式。

## 第二步：人工确认方案

在 `脱敏方案` 工作表中检查：

1. 不需要处理的字段，将“启用”改为 `N`。
2. 需要处理的字段，将“启用”保持为 `Y`。
3. 修改“处理方式”和“脱敏后样式（可修改）”。
4. 将所有启用项的“复核状态”改为 `已确认`。

常用样式：

| 处理方式 | 脱敏后样式 | 效果 |
|---|---|---|
| 稳定替换 | `供应商{序号:03d}` | 同一供应商始终替换为同一个编号 |
| 固定替换 | `测试物业公司A` | 整列统一替换为固定内容 |
| 保留末四位 | `***{末4位}` | 隐去前面内容，只保留末四位 |
| 删除 | 可留空 | 清空单元格 |
| 保留原值 | `{原值}` | 明确确认该字段不改变 |

`人工确认`不能直接执行。需要改为明确的处理方式，或者把“启用”改为 `N`。

## 第三步：执行脱敏

```bash
python3 excel_anonymizer.py apply \
  --input "/路径/原始数据" \
  --plan "/路径/脱敏方案_已确认.xlsx" \
  --output-dir "/路径/脱敏结果"
```

输出目录包括：

- 每个源文件对应的 `原文件名_脱敏.xlsx` 或 `.xlsm`。
- `脱敏方案_已执行.xlsx`。
- `脱敏执行记录.json`，记录实际处理数量和前后样例。

## 默认保护措施

- 不覆盖原始 Excel。
- 启用项没有全部确认时拒绝执行。
- 启用项仍为“人工确认”时拒绝执行。
- 公式单元格不会被直接修改，会在执行记录中列出跳过数量。
- 同一原值在多个文件中采用相同的稳定替换结果。
- 输出文件已经存在时默认停止；只有明确增加 `--overwrite-output` 才替换旧输出。

## 识别范围

工具会结合字段名称和单元格内容识别以下候选信息：

- 公司、客户、供应商、项目、利润中心、WBS、合同及内部编号。
- 姓名、手机号、邮箱、证件号码、银行账号、地址和统一社会信用代码。
- 摘要、备注、说明等自由文本会列为“人工确认”，不会自动执行。

自动识别只是候选清单，不能代替人工确认。方案文件中含有真实样例，应按受控资料保存，不应与脱敏后的普通数据包一同外发。

## 调整通用识别规则

`default_rules.json` 中每项规则可以配置：

- `header_patterns`：字段名称的通用匹配方式。
- `content_patterns`：单元格内容格式的通用匹配方式。
- `risk_level`：风险等级。
- `method`：默认处理方式。
- `template`：默认脱敏后样式。
- `template_variants`：编码列、名称列等不同字段形式对应的样式。
- `default_enabled`：扫描后默认是否启用。

新增或调整识别范围时只修改规则文件，不修改 Python 程序。每次生成的方案会记录实际使用的规则文件路径。
