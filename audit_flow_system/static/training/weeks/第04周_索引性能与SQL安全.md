# 第4周：索引、EXPLAIN、性能与SQL安全

## 本周目标

理解主键、普通索引和联合索引；能阅读 `EXPLAIN` 的关键字段；识别无范围大表查询、全表扫描和危险 SQL。

## 配套课件

- [01-IT审计基础能力培训](../../培训课件/01-IT审计基础能力培训.html)：复习数据库技术基础和审计证据质量。
- [02-IT审计财务知识](../../培训课件/02-IT审计财务知识_三大报表与业务数据.html)：思考优化前后为何不能改变业务口径。
- [03-IT审计日常工作AI应用](../../培训课件/03-IT审计日常工作AI应用.html)：重点学习“AI 生成 SQL/Python 的七个控制点”和工程化质量控制。

## 学习内容与练习

1. 阅读 `EXPLAIN` 的 `type`、`key`、`rows`、`Extra`。
2. 在 ITAS 中完成 `W04-Q01` 至 `W04-Q05`。
3. 将日期函数条件改写为范围条件，将无范围明细改写为索引范围加 `LIMIT`。
4. 比较优化前后 SQL 的业务含义，确认只优化访问路径、不改变口径。

## ITAS提交要求

- 题目只接受只读 SQL；`INSERT/UPDATE/DELETE/DROP/ALTER/TRUNCATE/CREATE/GRANT` 等会被拒绝。
- SQL 中不得包含多语句、注释绕过、`INTO OUTFILE` 或无界明细读取。
- 每道性能题在说明区填写预期索引、扫描风险、修改理由和口径一致性判断。

## 完成标准

- 能独立判断 5 条 SQL 的主要性能风险。
- 能解释为什么公共库不能自行建索引。
- 能说明静态校验、数据库执行计划和人工复核三者的边界。
