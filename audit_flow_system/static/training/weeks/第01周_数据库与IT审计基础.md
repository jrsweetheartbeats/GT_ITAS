# 第1周：数据库、IT审计与只读查询基础

## 本周目标

认识数据库、表、字段、主键、索引和数据类型；理解 ITGC、ITAC、接口、IPE、CAATs 与审计证据链；能安全查看 `imc`、`yuhu`、`soho` 的表清单、结构和少量明细。

## 学习内容与练习

1. 阅读本周课件章节，完成 `01_测试连接.py`、`02_查看表清单.py`、`03_查看表结构.py`。
2. 在 ITAS“学习刷题”中完成 `W01-Q01` 至 `W01-Q05`。
3. SQL 题覆盖 `SHOW DATABASES`、`SHOW TABLES`、`DESCRIBE` 和带字段清单、`LIMIT` 的明细预览。
4. 简答题说明主键与普通索引的区别，以及查询前为何必须确认数据源、范围和完整性。
