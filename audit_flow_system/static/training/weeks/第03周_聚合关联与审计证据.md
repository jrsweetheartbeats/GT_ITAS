# 第3周：聚合、关联与审计证据链

## 本周目标

掌握聚合、分组、`HAVING` 和表关联；理解数据粒度、一对多重复和关联前后核对；形成“SQL—结果—证据—结论”链条。

## 配套课件

- [01-IT审计基础能力培训](../../培训课件/01-IT审计基础能力培训.html)：重点学习 CAATs 全链条、数据来源/范围/完整性和 SQL 到证据的可追溯性。
- [02-IT审计财务知识](../../培训课件/02-IT审计财务知识_三大报表与业务数据.html)：复习业务流、凭证、总账和报表之间的关联。
- [03-IT审计日常工作AI应用](../../培训课件/03-IT审计日常工作AI应用.html)：学习用 AI 辅助解释查询，但保留人工口径核对。

## 学习内容与练习

1. 使用 `COUNT/SUM/AVG/MIN/MAX`、`GROUP BY`、`HAVING`。
2. 在 ITAS 中完成 `W03-Q01` 至 `W03-Q05`，包含 IMC、YUHU、SOHO 聚合题和关联核对题。
3. 每个关联题记录关联键、左右表粒度、关联前后行数及未匹配数量。
4. 简答题解释一对多关联为何会重复金额，以及如何验证。

## ITAS提交要求

- 聚合题可以不设明细 `LIMIT`，但必须有范围条件；下钻明细仍须 `LIMIT`。
- 在答案说明中写明指标定义、分组维度、排除项和核对过程。
- 系统只验证 SQL 安全和结构，不替代业务口径复核；最终口径由提交人负责。

## 完成标准

- 至少完成 3 个聚合指标、2 个分组维度和 1 项异常或未匹配检查。
- 关联后金额与行数变化均有解释。
- 结论可由提交的 SQL 和说明回溯。
