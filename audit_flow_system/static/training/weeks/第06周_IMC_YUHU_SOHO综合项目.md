# 第6周：IMC、YUHU、SOHO综合项目

## 本周目标

综合运用 SQL、Python、财务知识、IT 审计方法和 AI 辅助能力，完成一项有范围、有核对、有证据、有边界的分析成果。

## 配套课件

- [01-IT审计基础能力培训](../../培训课件/01-IT审计基础能力培训.html)：复习综合案例、CAATs 全链条和控制结论边界。
- [02-IT审计财务知识](../../培训课件/02-IT审计财务知识_三大报表与业务数据.html)：复习三大报表、业财映射和异常影响分析。
- [03-IT审计日常工作AI应用](../../培训课件/03-IT审计日常工作AI应用.html)：复习综合案例、隐私、复现和质量控制。

## 选题

- IMC：订单趋势、销售结构、凭证来源、科目分布或异常线索。
- YUHU：登录失败、API 错误、高耗时路由、文件外发或高风险命令。
- SOHO（乐聚天下）：订单趋势、支付履约、ERP 收入覆盖、材料成本覆盖、SKU 毛利或未匹配分析。

## ITAS刷题与提交

1. 完成通用题 `W06-Q01`、`W06-Q02`，再选择一个项目轨道：`W06-IMC-*`、`W06-YUHU-*` 或 `W06-SOHO-*`。
2. 在每题中提交基础核对 SQL、汇总 SQL、明细下钻 SQL及口径说明。
3. 报告答案需包含背景、数据源、期间、步骤、指标、异常线索、限制、待补证据和复现方式。
4. “规则命中”与“确认问题”必须分开表述；SOHO 不得导出姓名、电话、邮箱和详细地址。
5. 负责人在 ITAS 批阅区评分、反馈并要求订正；订正保留提交时间与校验结果。

## 完成标准

- 至少 2 张结果表、1 项数据质量核对、1 项分组汇总和 1 项明细下钻。
- SOHO 优先使用 `soho_ub_order_agg`、`soho_ub_order_finance_fulfillment`、`soho_ub_sku_profit_corrected`。
- SQL 全部通过系统静态安全校验，业务口径与结果由人工复核确认。
- 综合项目建议满分 200 分，160 分及以上通过。
