# 第5周：Python数据库编程与AI辅助分析

## 本周目标

用 PyMySQL 完成参数化只读查询、异常处理和 CSV 导出；正确使用 AI 辅助生成、解释和检查代码，同时保护凭据与客户数据。

## 配套课件

- [01-IT审计基础能力培训](../../培训课件/01-IT审计基础能力培训.html)：复习 CAATs 实施链路和可复现证据。
- [02-IT审计财务知识](../../培训课件/02-IT审计财务知识_三大报表与业务数据.html)：确保程序输出指标能回到业务和报表口径。
- [03-IT审计日常工作AI应用](../../培训课件/03-IT审计日常工作AI应用.html)：重点学习任务定义、隐私边界、可复现性及 AI 输出复核。

## 学习内容与练习

1. 跟做 `04_IMC只读分析示例.py`、`05_YUHU只读分析示例.py`、`09_SOHO只读分析示例.py` 和导出脚本。
2. 在 ITAS 中完成 `W05-Q01` 至 `W05-Q05`。
3. SQL 题检查参数占位、范围和行数限制；简答题提交 Python 核心代码或伪代码、运行方式和异常处理说明。
4. 验证密码来自环境变量或运行时输入，日志中不输出密码和无关敏感字段。

## ITAS提交要求

- 代码类答案粘贴到答案区；SQL 放在 SQL 区并单独校验。
- 可在项目材料区补充脱敏 CSV 和代码文件，ITAS 提交记录必须写明文件位置与结果行数。
- AI 生成内容必须由提交人运行、核对并说明修改点，不得把客户原始数据上传到未获批准的外部模型。

## 完成标准

- 查询至少接受 2 个参数，使用参数化执行，默认不超过 1000 行。
- 空结果、超时和权限错误均有清晰提示。
- 新环境可按说明复现，且代码中没有硬编码密码。
