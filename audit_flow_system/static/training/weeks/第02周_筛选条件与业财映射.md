# 第2周：筛选、排序、空值与业财映射

## 本周目标

掌握 `WHERE`、`AND/OR`、`IN`、`BETWEEN`、`LIKE`、空值、排序和 `CASE WHEN`；能把 IMC/SOHO 业务数据与财务报表科目、把 YUHU 日志事件与控制目标联系起来。

## 配套课件

- [01-IT审计基础能力培训](../../培训课件/01-IT审计基础能力培训.html)：复习 SQL 查询前的数据源、范围、完整性问题。
- [02-IT审计财务知识](../../培训课件/02-IT审计财务知识_三大报表与业务数据.html)：重点学习三大报表勾稽、销售 100/成本 60 示例和业务数据到财务影响的翻译。
- [03-IT审计日常工作AI应用](../../培训课件/03-IT审计日常工作AI应用.html)：学习如何把模糊任务改写为明确的数据范围和输出要求。

## 学习内容与练习

1. 跟做 IMC 凭证期间筛选、YUHU 日志时间筛选和 SOHO 订单状态筛选。
2. 在 ITAS 中完成 `W02-Q01` 至 `W02-Q05`。
3. 使用左闭右开日期范围；正确处理 `NULL`；用括号明确混合 `AND/OR` 的优先级。
4. 简答题说明一条业务异常可能影响的报表项目、认定和需要补充的证据。

## ITAS提交要求

- SQL 明细默认不超过 200 行，必须明确项目库、时间或业务范围。
- 校验失败时根据错误项修改后重新校验；不得通过注释、拼接或多语句绕过校验。
- 文字结论填写在题目“说明/答案”区域，不能把“规则命中”直接写成“已确认问题”。

## 完成标准

- 能解释筛选口径、空值处理和字段选择。
- 能从 IMC、YUHU、SOHO 各完成一条有限范围的查询。
- 能将技术异常转换成可复核的业务或财务影响假设。
